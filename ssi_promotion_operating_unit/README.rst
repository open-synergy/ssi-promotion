==========================
Promotion + Operating Unit
==========================

Glue module that adds Operating Unit support to the Promotion module.
Extends ``promotion_code`` and ``promotion_code_usage`` with
``mixin.single_operating_unit``, restricting visibility of both to the
operating units assigned to the current user.
