# Edit Promotion Code Usage

> **Module:** ssi_promotion_operating_unit
>
> **Extends:** ssi_promotion — model `promotion_code_usage`, aksi `02-edit`

## Additional Fields

When this module is installed, the edit form gains one additional field, visible only to
users in the **Multiple Operating Unit** group
(`operating_unit.group_multi_operating_unit`):

- **Operating Unit**: The operating unit this promotion code usage belongs to. Not
  required. Change if needed.
